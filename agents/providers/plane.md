# Plane selection guidance

Plane is an optional scaffold choice. Its AI-DLC tracker lifecycle adapter and
guided connection are currently unavailable. Selecting it, installing a native
connector or delivering these instructions does not enable AI-DLC tracked-work
publication, start or finish. Readiness reports this limitation explicitly.

Native harness tools have their own account, endpoint, authentication and tool
inspection requirements; this scaffold does not assert an available connection.
Do not infer workspace/project IDs, redirect another project's credentials or
install Plane for a project that selects GitHub or Jira. Use an implemented
tracker when AI-DLC lifecycle operations are required. Later Plane qualification
requires an explicitly chosen destination and separately reviewed implementation.
