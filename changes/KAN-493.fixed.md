- The workflow plugin's PreToolUse hook now denies PowerShell's own deletes (`Remove-Item` and its aliases `ri`, `del`, `erase`, `rd`, `rmdir`), also inside a script block such as `ForEach-Object { ... }`, and knows git by its name, so `git.exe`, `git.cmd`, `/usr/bin/git` and, in PowerShell, `C:\Program Files\Git\cmd\git.exe` get the same checks as `git`. git's global options no longer hide the subcommand (`git -C repo reset --hard` is denied), and the line after `cmd /c` is judged with cmd.exe's own deletes (`del`, `erase`, `rd`, `rmdir`) (KAN-493).
