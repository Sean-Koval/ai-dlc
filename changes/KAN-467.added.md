- `ai-dlc knowledge stats <records> --since <time>` measures the 1.0 outcomes from git, pull requests, the tracker and the capture run log: capture cost per source and per transcript hour, review time and reviewer edits, first-push green agent pull requests, stale and expiring records, and records per author. `--report` writes `reports/<week>.md`; `--json` prints the numbers. The run-log format is `contracts/capture-run.schema.json`, and the scm role gains the optional `pull_requests` operation. A reusable workflow, `.github/workflows/knowledge-stats.yml`, opens the weekly report as a pull request.
