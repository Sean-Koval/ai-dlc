- `ai-dlc knowledge stats <records> --since <time>` measures the 1.0 outcomes from git, pull requests, the tracker and, with `--log`, the capture batch's run log: capture cost per source and per transcript hour, review time and reviewer edits, first-push green agent pull requests, stale and expiring records, and records per author. `--report` writes `reports/<week>.md`; `--json` prints the numbers. The run-log format is `contracts/capture-run.schema.json`; the batch keeps the log where it runs, a missing or wrong-shaped log is an error, and a failed Source's unknown usage is counted as unknown, not zero; and the scm role gains the optional `pull_requests` operation. A reusable workflow, `.github/workflows/knowledge-stats.yml`, opens the weekly report as a pull request, with capture reported as not measured.
