- `ai-dlc doctor` (and `machine doctor`) outside an adopted repository runs a machine preflight
  instead of stopping at "no ai-dlc.toml" (KAN-363). It reports git; gh and whether it is signed in
  to `GH_HOST` (default github.com); the `claude` and `codex` CLIs (`--agent-client` makes one
  required; otherwise one installed client is enough); a real `python3`, flagging the macOS
  Command Line Tools stub; the bootstrap directory on `PATH`; mise, now optional; and the network
  settings bootstrap and mise read (`HTTPS_PROXY` without its credentials, `SSL_CERT_FILE`,
  `UV_NATIVE_TLS`, a GitHub token). It contacts nothing unless `--probe-versions` is given, which
  adds `--version` probes and `gh auth status`. Each failing item names one next action, and doctor
  exits 1 when a required item is missing.
- `project readiness` (and doctor inside a repository) reports a selected agent client's CLI as a
  missing tool when it is not on `PATH`, instead of treating delivered guidance as ready.
