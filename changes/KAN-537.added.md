- The tracker role's read (`tracker_get`) now reports the item's `kind` (work, epic or
  decision), its `category` (todo, in_progress or done) and `blocked_by`: the items that
  block it, each with its key, category, kind and labels (KAN-537). jira-cloud reads the
  issue type and the inward Blocks links, reading each blocker for its labels. When link
  evidence or a blocker can't be read, it still returns the item and leaves `blocked_by`
  out, which means "can't tell", never "unblocked".
  github-issues answers work with no blockers.
