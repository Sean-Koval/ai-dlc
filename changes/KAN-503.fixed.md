- Customer knowledge fails closed instead of falling back to the team repository (KAN-503).
  `knowledge pull-transcripts` skips every transcript and writes nothing until `knowledge.toml`
  has a `[[transcripts.customers]]` rule or `[transcripts] no_customers = true`; both together
  are refused. `knowledge check` fails a `boundary: customer` record in any repository whose
  `knowledge.toml` does not declare `[repo] boundary = "customer"`. `knowledge promote` runs
  only from a customer repository and always needs `--to`; the team-repository promote path
  is removed.
