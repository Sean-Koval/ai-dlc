- `ai-dlc knowledge install` installs a team-harness channel, clones `KNOWLEDGE_REPO` and adds the knowledge pre-commit hook without touching your own Claude setup, then prints the harness's `claude mcp add` and plugin commands to run; `ai-dlc knowledge doctor` (and `ai-dlc doctor --knowledge`) prints one pass, fail, skip or unverified line per check, failing with the command until each MCP server is configured. `bootstrap.sh --knowledge` runs both.
