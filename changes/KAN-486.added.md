- A new page brings its own catalog entry in `docs/catalog.d/<id>.toml`, with `nav` naming its site section, so two pull
  requests that each add a page no longer conflict on `docs/catalog.toml` or the `nav` in `mkdocs.yml`. The site is
  built from `site.yml`, which `scripts/site_config.py` writes. `scripts/build_contracts.py` regenerates
  `contracts/manifest.json` and the operation schemas, so a conflict there is resolved by rerunning it.
