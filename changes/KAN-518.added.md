- `tracker_create` can set a work type, custom fields, a parent and issue links where
  the tracker offers `create_typed` (Jira does), and reads each link back (KAN-518).
- `tracker_create_decision` files a question only a person can answer through the
  tracker role. Jira files the configured Decision type with Options, Recommendation,
  Default if unanswered, Scope and Due, then links it as blocking the work item. A
  repeat returns the first Decision; `exec:agent` is refused. Configure it under
  `providers.<id>.decision`; the provider offers `decide` only then.
