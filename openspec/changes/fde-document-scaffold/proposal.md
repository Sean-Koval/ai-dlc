## Why

Issue #50 has an independently specified local FDE documentation scaffold. The
referenced production ai-docs source is absent from this machine, so authentic
Confluence conversion/client port and live publication remain outstanding in
team-document-publication. This change delivers local scaffolding without
claiming those blocked requirements are complete.

## What Changes

- Add `ai-dlc fde scaffold` for a charter and seven ordered stage landing pages.
- Add `ai-dlc fde check` for structural and explicit stage-gating validation.
- Generate portable engagement agent guidance and document configuration.

## Capabilities

### New Capabilities
- `fde-document-scaffold`: local engagement documents and stage validation.

## Impact

Documentation application service, thin CLI, explicit YAML dependency, tests,
runbook and catalog. No provider role, network access, vault access, or automatic
tracker finish is introduced. #50 stays open for publication work.
