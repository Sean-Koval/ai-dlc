## Why

The existing Rust CLI only copies agent templates. A new development computer also
needs runtimes, client configuration, project checks and the current working process.
These choices need editable profiles and provider boundaries so tools can change.

## What Changes

- Replace the primary CLI with a Python/uv package, preserving scaffold aliases.
- Add verified standalone bootstrap, scoped configuration, delegated provisioning,
  project preparation, check receipts and target capability declarations.
- Add versioned providers, reviewed work records, recovery journals and completion gates.
- Add staged Copier adoption/update, shared agent instructions, skills and hooks,
  existing-vault knowledge operations and repository documentation templates.
- Generate CI from the project check manifest and record release verification gaps.

## Capabilities

### New Capabilities
- `portable-development`: portable preparation, agent configuration and evidence-gated work.

## Impact

Python becomes the primary distribution. Existing Rust and npm packaging is retained
as historical compatibility material and disabled for further publication. Runtime
installation, sign-ins, cloud capabilities and remote API operations remain explicit.
