# Team sources

## Why
Profiles need pinned, reviewable team skills and rules without running remote code or copying credentials. Issues #83 and #84 authorize one delivery covering native and teamai source layouts.

## What Changes
- Add schema 4 personal source subscriptions and machine role selection, locking source commits alongside the profile.
- Validate bounded non-executable source trees; render selected skills, rules, MCP commands and supported AI-DLC hook declarations with ownership checks.
- Preview source updates on sync, activate only with --apply, and notify at session start without fetching content.
- Read the supported teamai layout without installing teamai. The explicit acceptance requirement wins over conflicting prose: env/ content is refused.

## Capabilities
### New Capabilities
- `team-sources`: pinned enrollment, filtering, safe rendering and teamai import.

## Impact
Environment enrollment and lock, scoped configuration, harness rendering and hooks, teamai adapter, enrollment runbook, profile example and product direction.
