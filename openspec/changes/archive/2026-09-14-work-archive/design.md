# Archive command design

Accept only this record's active openspec/changes/<id> directory on its bound branch. Invoke OpenSpec archive --yes --json inside the provider. Validate the returned archive identity and proposal/tasks; compute promoted paths from the source delta capabilities when specsUpdated is true because installed OpenSpec 1.5 JSON reports archive path/totals, not individual promoted paths. Repoint spec and any plan inside the active change. Stage only the selected active/archive paths, promoted spec files and work record; preserve unrelated staged/dirty files and refuse dirty shared canonical specs before promotion. Failed commands expose uncertainty and retain files for inspection. Status becomes local-only; PR warns on an active specification. Finish includes the archive remedy while preserving merged revision, clean specification and completed task gates. Update shared rendered guidance and existing delivery docs.
