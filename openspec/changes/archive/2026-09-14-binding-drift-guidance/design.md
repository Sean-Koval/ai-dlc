# Binding drift guidance

Preserve every identity calculation and refusal. Extend the existing message prefix with the actual supported workflow: review the current role configuration and record, remove only its drifted binding, validate the record, then let a normal mutation persist the reviewed binding. Finished records retain historical identity and use the binding-independent repository check. Add no repair command or implicit mutation. CLI hints repeat drift messages only when all errors are drift errors; mixed failures retain ordinary diagnostics.
