# Frontend capability pack

## Why
Issue #79 needs runnable smoke and screenshot evidence behind the existing frontend design workflow.

## What Changes
An opt-in node frontend capability adds pinned Playwright dependencies, an offline-safe smoke check and setup guidance. Design capture records viewport screenshots and named visible-selector states under a contained output directory.

## Impact
Copier templates, setup capability selection, module catalog, CLI/harness capture service and design-evaluation guidance. No hosted browser, Storybook or visual-diffing service.
