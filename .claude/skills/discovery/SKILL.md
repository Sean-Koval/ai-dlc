# Discovery

Produce a bounded problem statement, known evidence, assumptions, open questions, and the smallest useful next investigation. Distinguish requested outcomes from suggested implementation. Consult existing repository architecture and product context. Do not publish work or create formal specifications merely because discovery occurred.
