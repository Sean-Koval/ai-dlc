# Review Inbox

Return classifications, duplicates, missing context, and suggested next actions. Consult tracker priorities and repository scope before recommending work. Separate personal notes from durable design/decisions. Publication or external replies require the user’s authorization; use services to validate and link the reviewed work. Do not silently turn every idea into a ticket.

Resolve provider-specific commands from the configured role provider’s instructions. The agent supplies judgment; services store, validate, and link artifacts.
