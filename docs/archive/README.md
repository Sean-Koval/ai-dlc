# Historical material

These records preserve previous designs, research and delivery context. They are
not current setup instructions, roadmap commitments or evidence that deferred work
shipped. Read [the current documentation map](../index.md) first.

- `legacy/`: earlier repository layouts and Rust implementation plans.
- `planning/`: superseded or cancelled assessments and unmatched execution plans.
- `research/`: historical template comparisons and generation prompts.

Execution plans with a matching OpenSpec change were relocated into that change.
Original revisions remain available through Git history. Dated verification
snapshots retain original path/hash observations; relocation does not refresh them.
