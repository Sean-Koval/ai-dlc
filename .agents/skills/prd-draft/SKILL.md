# Prd Draft

Use the PRD template to describe audience, problem, measurable outcomes, acceptance criteria, scope, constraints, risks, and open questions. Link supporting evidence. Clearly mark assumptions and draft status. Store durable product rationale in repository docs/design when requested. Formal behavior belongs to the specification role, not a duplicated PRD spec system.

Resolve provider-specific commands from the configured role provider’s instructions. The agent supplies judgment; services store, validate, and link artifacts.
