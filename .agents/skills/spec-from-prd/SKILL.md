# Spec From Prd

Check PRD status, scope, acceptance criteria, and unresolved decisions. Produce requirements and scenarios through the selected specification role using its provider-supplied instructions. Link back to the PRD and work record. Do not maintain a second formal spec copy in repository design docs. Stop for unresolved product decisions that materially change behavior.

Resolve provider-specific commands from the configured role provider’s instructions. The agent supplies judgment; services store, validate, and link artifacts.
